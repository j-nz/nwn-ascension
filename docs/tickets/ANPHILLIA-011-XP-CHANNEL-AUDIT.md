# ANPHILLIA-011 — XP reward-channel audit

**Status:** RESEARCH / AUDIT  
**Parent:** ANPHILLIA-000  
**Donor:** https://github.com/mtijanic/anphillia/tree/master/xp

## Objective
Review—not import—Anphillia's combat/RP/exploration XP separation and banking/throttling ideas against Ascension's current XP architecture.

## Questions
Map current XP sources/caps. Identify genuine gaps for exploration, investigation or community activity. Determine whether deferred/banked awards solve a real problem. Evaluate daily thresholds/throttles against Ascension's level cap and progression goals.

## Guardrails
Do not replace the current XP system. Do not introduce hidden daily punishment/exhaustion without explicit approval. Every new reward source must be auditable and exploit-resistant.

## Acceptance
Current-state XP map; donor gap analysis; explicit adopt/reject decision for each mechanism; implementation, if any, split into separately approved tickets.
